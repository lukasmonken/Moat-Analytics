# Dados

`raw/` recebe arquivos originais. `processed/` recebe dados internos normalizados. O Git ignora o conteúdo desses dois diretórios.

`public/` fica reservado a snapshots cuja redistribuição foi autorizada e cuja qualidade foi validada. O M0 não contém snapshots. O build do site não copia estes diretórios.
